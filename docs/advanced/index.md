# Advanced

This section is for operators who need to go past the normal commands: to read the store's files directly, or to remove a memory after something has gone wrong. Day-to-day use is in the [User Guide](../user-guide/index.md).

- [Store Files](store-files.md): what each file under `.summem/` holds, for reading and debugging.
- [Emergency Surgery](surgery.md): remove one note from a store with `surgery.py`, for example a note that holds personal data.

Rewriting naps from an older file format is in [Upgrading](../user-guide/upgrading.md#older-nap-files).
