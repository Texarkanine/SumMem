# Project Memory

Shared memory for this repository is managed through SumMem, invoked as `.summem/summem`.

## At Session Start: Activating SumMem

If this conversation does not contain a root-wake `== SumMem Usage ==` block you can still see and follow, run `.summem/summem wake` from the repository root. Do not skip because of a remembered wake or the footer alone.

## While Working: Register Memories

`.summem/summem note "…"` records one short line for a fact another contributor would still need. Personal, machine-local, and user preference facts stay out. Follow further instructions that wake or `note` printed.

Never invent filenames, rewrite note bytes, or delete memory files by hand. The script is the only writer. The files it writes are part of your work; do not leave them untracked.
