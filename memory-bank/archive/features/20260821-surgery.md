## IMPLEMENTATION

[`surgery.py`](../../../surgery.py) loads sibling `summem` via `SourceFileLoader`. `locate_note` matches note text / filename only (never nap captions as delete targets). `plan_break_out` / `excise_note` split every view nap whose tree still contains that filename (`rematerialize_child` then `_unlink_node`), then unlink the loose note, then `heal_view`. Mutate uses `with_store_lock(parent, fn)`; dry-run does not. CLI: `--path`, `--contains`, `--dry-run`, optional `NAME` (name wins; contains must still match).

Operator docs: [`docs/surgery.md`](../../../docs/surgery.md), linked from [README](../../../README.md) and [`docs/index.md`](../../../docs/index.md).

## LESSONS LEARNED

Calling `heal_view` while the target is a rematerialized loose note still covered by a larger overlapping pack subset-drops that note and leaves the sentence in a `.tree`. Split every containing view nap first, unlink the loose file, then heal.
