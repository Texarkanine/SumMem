## LESSONS LEARNED

- `fold_request` is shared with `nap`. Putting `Saved.` in that helper is the lie this bug was about. Prefix on `main`'s `note` branch is the whole design.
- Silent-stdout tests (`out == ""` on `note`) were the bug encoding.
- If ACK had been assumed from the start, `note` would never have been silent. Printing ACK immediately after `write_note` (before heal) is closer to OptMem; post-lock still matches the wire contract when heal succeeds.
