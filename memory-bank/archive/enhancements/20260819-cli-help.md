## REQUIREMENTS

- Bare / `-h`: catalog of every command; `--path` on all but `start`; footer explains omit → `$PWD`.
- `-h <command>` and `<command> -h` both work. `-h` is help, not an unknown command.
- No repository: store commands fail; help does not. Error text says “repository,” not “git.”
- Tests load repo-root `summem`. Printed invocations use `CLI_NAME = "summem"`. `ensure_store` still copies into `.summem/summem` and does not overwrite.

- Target unreadable pack → `unreadable pack` (rc 1 at CLI). Sibling bad tree → skip, no traceback.
- Fold prompt uses configured `ENTRY_CHARS`. Explicit `note` arm; leftover `cmd` cannot write a note.
- VISION: `start` is no-walk-up inside a repository; one root auto-create rule; no “explicit config command.”

## LESSONS LEARNED

- `JSONDecodeError` subclasses `ValueError`. Asserting `ValueError` stays green while the CLI still leaks the parser message.
- Printed invocation strings are a dependency of moving the driver. Do not use `sys.argv[0]`: that is this invocation, not a later recipe (in-process pytest is the cheap reason, not the real one).
- `parse_args(argv)` discards a `-h <command>` rewrite; the copy has to reach parse.
- A local untracked `.summem/summem` can make collection succeed; SCRIPT equality is still the red.

## PROCESS IMPROVEMENTS

Catalog-prefix and `unreadable pack` reds belong in the first plan, not the third preflight. `"summem wake" in catalog` is not a red for dropping the `.summem/` prefix.

## TECHNICAL IMPROVEMENTS
